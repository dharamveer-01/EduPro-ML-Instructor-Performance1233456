# EduPro Instructor Performance and Course Quality Evaluation

## Project Overview

EduPro is an end-to-end Machine Learning and Analytics system designed
to evaluate instructor performance and course quality in an online
education platform.

The system combines data validation, feature engineering, statistical
analysis, machine learning, explainable AI, risk intelligence,
segmentation, anomaly detection, monitoring, retraining, FastAPI
serving, Streamlit visualization and Docker deployment.

## Major ML Components

- Instructor Rating Prediction
- Course Quality Prediction
- Instructor Risk Classification
- Course Risk Classification
- Instructor Clustering
- Course Clustering
- Instructor Anomaly Detection
- Ensemble Learning
- Automatic Model Selection
- Explainable AI
- Data Drift Monitoring
- Prediction Drift Monitoring
- Automatic Retraining
- Champion-Challenger Model Management

## Important Methodological Note

Some risk labels are derived from rating-based rules. Therefore those
classification models should be interpreted as decision-support and
classification demonstrations rather than independent causal forecasts.

Anomaly detection identifies unusual patterns and does not automatically
mean that an instructor or course is poor.

XAI feature contributions describe model behavior and should not be
interpreted as causal effects.
