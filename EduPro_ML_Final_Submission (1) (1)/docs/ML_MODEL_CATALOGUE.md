# Machine Learning Model Catalogue

## Instructor Rating Prediction

Models evaluated include Linear Regression, Ridge, Random Forest,
Extra Trees, Gradient Boosting and HistGradientBoosting.

## Course Rating Prediction

The same family of regression algorithms is evaluated for course quality.

## Instructor Risk

Classification models include Logistic Regression, Random Forest,
Extra Trees, Gradient Boosting and HistGradientBoosting.

## Course Risk

Classification models are evaluated using accuracy, precision, recall,
F1 score and ROC-AUC where applicable.

## Segmentation

KMeans clustering is evaluated using Silhouette, Davies-Bouldin and
Calinski-Harabasz metrics.

DBSCAN is also evaluated as an alternative clustering approach.

## Anomaly Detection

Isolation Forest is used to identify unusual instructor-level patterns.

## Ensemble Learning

Voting and stacking approaches are evaluated against base learners.

## Explainable AI

Model-agnostic perturbation analysis is used to estimate feature
contributions to model predictions.
